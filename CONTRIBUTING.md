# Mitwirken an Belegt

Issues und Pull Requests sind willkommen. Belegt ist ein selbst gehostetes Dokumentenarchiv mit GoBD-Modus. Wie du es
lokal startest und testest, steht in der [Entwicklung](docs/entwicklung.md). Für alle, die mitmachen, gilt unser
[Verhaltenskodex](CODE_OF_CONDUCT.md).

## Fehler und Wünsche melden

Neues Issue über die Formulare: [Issue anlegen](https://github.com/Speicherstadt/belegt/issues/new/choose). **Keine echten
Dokumente, Mails, Adressen oder Zugangsdaten** in Issues, Screenshots oder Logs. Sicherheitslücken bitte privat melden,
siehe [SECURITY.md](SECURITY.md).

## Pull Requests

Wie ein Beitrag entsteht (Aufgabe übernehmen, Branch, Titel, Prüfungen, Review), steht unter
[Mitwirken](docs/mitwirken.md). Mit einem KI-Werkzeug geschriebene Beiträge sind willkommen; du verantwortest sie wie
eigenen Code und nennst das Werkzeug im Pull Request. Agenten lesen zuerst [AGENTS.md](AGENTS.md).

## Lizenz

Mit einem Beitrag stellst du ihn unter die [AGPL-3.0](LICENSE).
